# DesktopCal 桌面日历 — 产品需求文档

## 产品简介

桌面日历（DesktopCal）是一款基于 Wails v2 的桌面日历应用，将日历直接嵌入桌面。支持农历、节气显示，双击日期格子快速记录事项，提供多主题、窗口置顶、数据导入导出等功能。

### 技术栈

- **后端**：Go 1.25 + Wails v3 + SQLite
- **前端**：Vue 3 (Composition API) + TypeScript + Pinia + Vite
- **构建**：Makefile（后端）+ npm（前端）

## 一、日历显示

### 1.1 月视图布局

- 以月为单位展示日历，顶部显示年月标题
- 星期行显示周几标题，周末列高亮区分
- 每个日期单元格显示网格线边框

### 1.2 动态行数

- 根据当月天数和起始星期，自动计算所需行数（4、5 或 6 行）
- 默认只显示当月日期，月头月尾可显示临近一周的上下月日期
- 非当月日期以半透明样式显示
- 当天所在的周居中显示

### 1.3 日期单元格内容

- **公历日期**：显示日号，当天加粗高亮并带小圆点标记
- **农历信息**：显示对应农历日期，初一显示月名（如"正月"、"二月"）
- **节气**：节气当日优先显示节气名称（如"立春"、"清明"），替代农历
- **事件预览**：每条前置数字序号（`1.`、`2.`…，与单日弹窗行号对应），按日期格子高度撑满显示（不限条数），放不下的自动裁剪，右下角以 `+N` 提示剩余条数，不使用滚动条
- **完成状态**：已完成事件标题显示删除线
- **自定义背景色**：如设置了背景色，单元格显示对应色调

### 1.4 交互

- **单击**：选中日期，高亮显示，右侧面板显示该日详情
- **双击**：打开事件编辑弹窗
- **前后翻月**：左右箭头按钮切换上/下月
- **今天按钮**：快速跳转回当月并选中今天

## 二、事件管理

### 2.1 事件编辑弹窗

- 弹窗顶部显示日期信息：公历日号、星期、农历（月名+日名）、天干地支纪年、生肖、节气
- 使用**单个纯文本文本区域**编辑事件，每行一条
- 左侧显示行号，与文本区域滚动同步
- 不使用结构化表单（无独立标题、时间、描述、颜色字段）
- 弹窗支持拖拽调整大小，尺寸自动记忆

### 2.2 完成标记

- 右键点击行首区域，切换该行事件的完成/未完成状态
- 已完成事件在行首显示 `✓` 前缀
- 在文本区域中可直接手动输入/删除 `✓` 前缀

### 2.3 快捷键

- `Ctrl+Enter`（macOS: `Cmd+Enter`）：保存并关闭弹窗
- 弹窗打开时自动聚焦文本区域

### 2.4 事件排序

- 同一天的事件按完成状态排序：未完成的在前，已完成的在后
- 同状态内按开始时间排序

### 2.5 事件属性

- 标题（必填）
- 日期（必填）
- 开始时间、结束时间（可选）
- 颜色标记（默认 `#4A90D9`）
- 完成状态
- 创建时间、更新时间（自动记录）

## 三、农历与节气

### 3.1 农历计算

- 支持公历转农历，覆盖 1900–2100 年
- 显示农历月名（正月、二月…腊月）、日名（初一、初二…三十）
- 支持闰月显示（前缀"闰"）
- 天干地支纪年（如"丙午年"）
- 生肖年（鼠、牛、虎…猪）

### 3.2 节气

- 显示 24 节气（小寒、大寒、立春…冬至）
- 节气当日在日历单元格中替代农历显示
- 节气在事件弹窗头部独立显示

## 四、设置

### 4.1 窗口透明度

- 范围 30%–100%，步进可调
- 使用 CSS `opacity` 实现，不使用原生窗口透明

### 4.2 窗口尺寸

- 宽度：800px–1600px，步进 50px
- 高度：500px–1000px，步进 50px

### 4.3 颜色主题

提供 4 种主题：

| 主题 | 主背景色 | 说明 |
|------|---------|------|
| 深色 | `#1e1e2e` | 默认主题，深色背景 |
| 浅色 | `#f5f5f5` | 浅色背景 |
| 蓝色 | `#1a3a5c` | 蓝色调深色背景 |
| 绿色 | `#1a3c2e` | 绿色调深色背景 |

### 4.4 窗口置顶

- 开关式：开启 / 关闭
- 开启后窗口始终显示在其他窗口之上

### 4.5 编辑框字体大小

- 范围 10px–24px
- 影响事件编辑弹窗中文本区域和行号的字号

### 4.6 每周第一天

- 周日（默认）或 周一
- 切换后星期行和日历网格自动调整

### 4.7 显示农历

- 开关式：开启（默认）/ 关闭
- 关闭后日历单元格和事件弹窗中不再显示农历信息

### 4.8 显示节气

- 开关式：开启（默认）/ 关闭
- 关闭后日历单元格和事件弹窗中不再显示节气名称
- 节气关闭后，节气当日仍显示农历（如开启农历）

### 4.9 显示模式

- 宽松模式（默认）：每月单独一页，不混入其它月
- 紧凑模式：月历连续排布，交接处无空格

### 4.10 关闭时最小化到托盘

- 开关式：开启（默认）/ 关闭
- 开启后关闭窗口时程序保留在系统托盘，不退出
- 关闭后点击托盘图标可恢复窗口

### 4.11 开机自启动

- 开关式：开启 / 关闭（默认关闭）
- macOS：通过 `~/Library/LaunchAgents/com.desktopcal.plist` 管理
- Windows：通过注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 管理

### 4.12 全局快捷键

- 可自定义快捷键（默认 macOS: `Cmd+Shift+C`，Windows: `Ctrl+Shift+C`）
- 按下快捷键时显示/隐藏主窗口
- 在设置页"快捷键"标签中配置

### 4.13 编辑框尺寸

- 编辑框宽度和高度可独立设置
- 支持拖拽调整大小，自动记忆
- 设置项：`editorWidth`、`editorHeight`

### 4.14 设置持久化

- 所有设置项保存在 SQLite `settings` 表中
- 批量读取和写入，使用事务保证一致性

## 五、数据导入导出

### 5.1 导出

- 导出为 JSON 文件
- 包含全部数据：事件、日期背景色、设置项
- 文件名格式：`desktopcal-backup-YYYY-MM-DD.json`

### 5.2 导入

- 从 JSON 文件导入（覆盖现有数据，先清空再写入）
- 从桌面日历官方软件文本格式导入（按日期合并去重）
  - 格式：`[YYYY-MM-DD]` 日期头 + 虚线分隔 + `1. 任务` 编号行
  - 识别 `✓` 或 `√` 前缀为已完成任务
  - 按 `(date, title)` 去重，已有任务保留，仅插入新任务
- 导入后自动刷新日历显示

## 七、数据存储

### 7.1 数据库

- SQLite 数据库，存储路径：`$CONFIG_DIR/desktopcal/calendar.db`
- macOS: `~/Library/Application Support/desktopcal/calendar.db`

### 7.2 数据表

| 表名 | 说明 |
|------|------|
| `events` | 事件表（ID、标题、描述、日期、时间、颜色、完成状态等） |
| `day_backgrounds` | 日期背景色表（日期、颜色） |
| `settings` | 设置表（键值对） |

## 八、编码规范

### 8.1 Go 后端

- 单个 Go 文件不超过 150 行，超过需拆分
- 错误信息使用中文
- 内部包放在 `internal/` 下
- 数据模型集中在 `internal/model/model.go`

### 8.2 前端

- Vue 3 Composition API + `<script setup>` 语法
- TypeScript strict 模式，不使用 `any`
- 组件 PascalCase 命名
- `wailsjs/` 目录不手动编辑

### 8.3 通用

- 缩进：Go 用 Tab，前端用 2 空格
- 编码 UTF-8，换行符 LF
- 提交信息使用中文
