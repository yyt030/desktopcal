# DesktopCal 桌面日历 — 产品功能文档

## 产品简介

桌面日历（DesktopCal）是一款将日历直接嵌入桌面的效率工具，成立于 2011 年 5 月。用户可以在桌面上双击日期格子快速记录事项，同时支持农历、节气、自定义背景、云端同步等功能，永久免费提供。

**支持平台：** Windows XP / 7 / 8 / 10 / 11、macOS

---

## 核心功能

### 1. 双击记录

在桌面上双击任意日期格子，即可开始输入待办事项、日程安排、生日、纪念日等信息。无需打开额外窗口，操作直观便捷。

### 2. 万年农历

内置万年农历，支持公历与农历对照显示，方便查看传统节日、节气等信息。

### 3. 节气与节庆提醒

自动标注二十四节气及传统节日，帮助用户不错过重要节日和纪念日。

### 4. 自定义背景色

任意一天都可以设置自定义背景颜色，让每一天都是彩色的。用户可以根据心情、重要性或分类为不同日期设置不同的背景色。

### 5. 数据导入导出

提供强大的数据导入导出工具，支持在不同设备间轻松迁移日历数据，方便备份和恢复。

### 6. 打印日历

支持将日历打印为纸质版本，方便离线查看或张贴。

### 7. 云端同步

- 数据自动同步至云端，多端实时同步
- 支持历史记录回滚，数据安全有保障
- 换设备后登录账号即可恢复所有数据
